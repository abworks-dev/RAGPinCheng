# WORKLOG 强制记录规则

本规则全局适用。详细格式、排序和内容要求以根目录 `CLAUDE.md` 的“每次任务必须更新工作日志”章节为唯一标准。

- 除下条纯生产验收例外外，每个端到端任务或已批准执行阶段实际完成后、发送最终回复前，更新根目录 `WORKLOG.md`；同一阶段的实现、CI 修复、合并、workflow 重跑和验收统一记录，不为中间进度或失败尝试重复建项。
- 日志优先随当前功能提交或同一交付 PR 更新。合并后执行的纯生产验收已有不可变 workflow/审计记录时，不得仅为一条日志创建独立 PR 并触发全量 CI；可在下一次正常仓库交付中补记，并在当前最终回复中明确审计入口和待补记状态。
- 时间前缀是强制格式，不是示例：每条新任务记录的三级标题必须完整写成 `### HH:mm — 简短任务名`。
- `HH:mm` 必须是任务完成时的 `Asia/Shanghai` 24 小时时间；写入前先获取当前时间，不得猜测。
- 禁止新增 `### 任务名` 形式的无时间标题，也不得先省略时间、留待以后补充。
- `### --:-- — 简短任务名` 仅可用于整理完成时间确实无法确认的历史记录，不得用于当前任务。
- 同一天内按完成时间正序追加；写入后检查本次新增的每个三级标题均匹配 `^### ([01][0-9]|2[0-3]):[0-5][0-9] — .+`。
- 若检查发现本次新增标题缺少有效时间前缀，必须在最终回复前修正。
