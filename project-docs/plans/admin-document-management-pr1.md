# 管理端资料管理工作流 PR1

- 状态：已完成，用户验收通过
- 风险等级：R2
- 实施日期：2026-08-05

## 目标

将管理端资料页从“上传表单 + 两张独立表格”调整为资料列表优先的日常管理工作流，并在不迁移数据库的前提下统一展示资料当前索引生命周期。

## 已实施范围

- 资料列表作为主视图，上传移入右侧抽屉；
- 合并已索引 Parent 与每个源文件最近一次 `index_jobs` 状态；
- 增加总数、处理中、可检索、失败四类统计；
- 搜索、分类、类型、语义状态筛选和分页改为服务端执行；
- 上传支持拖放、多文件队列、逐文件移除和前置格式校验；
- 删除默认只移除索引并保留源文件，删除源文件必须显式选择；
- 索引任务降级为折叠的“索引活动”辅助视图；
- 主列表不显示服务端绝对路径或原始异常详情。

## 明确不做

- 不迁移 `app.sqlite`、`parents.sqlite` 或 Qdrant Schema；
- 不新增详情预览、批量移动、批量删除、标签或目录树；
- 不改变上传、重试、删除接口的认证与 CSRF 边界；
- 不访问真实资料，不部署生产，不重建索引。

## 兼容与回滚

资料 ID 由源路径做稳定哈希派生，仅用于本次列表 DTO；现有删除接口仍使用既有源路径契约。回滚时可整体回退本 PR 的 API DTO、聚合查询和管理页面，不需要回滚数据库或索引数据。

## 验证

- 后端资料聚合与语义状态筛选专项测试；
- 前端资料页、API client 及全量组件测试；
- TypeScript 与 Vite 生产构建；
- 虚构 API 数据下的桌面浏览器视觉检查；
- 用户按 `project-docs/USER_ACCEPTANCE.md` 和交付清单完成非敏感样本验收。
