# 资料管理与共享资料源布局设计

## 状态

已获用户确认，作为后续 R2 实施的设计基线。本设计只调整管理后台的信息架构与入口，不在本阶段修改业务 API、数据库或外部目录配置。

## 目标

1. 让“转录任务”页面优先呈现统计和可处理的视频列表。
2. 消除“资料管理 / 转录任务”的重复标题层级。
3. 将共享资料源从转录任务工作区移到管理员设置区域。
4. 保持共享资料源的视频能力不变，并为未来文档资料扩展留下清晰边界。

## 非目标

- 不在本阶段修改 `EXTERNAL_MEDIA_ROOTS_JSON`、容器挂载或真实共享目录。
- 不在本阶段增加 PDF、Office、图片或其他文档类型的扫描和解析。
- 不重构现有视频外部资料源的数据表、扫描协调器或转录队列。
- 不改变普通用户的资料可见性、审核、发布和索引权限。

## 信息架构

管理后台内容管理保留以下子页面：

```text
资料列表 | 回收站 | 上传任务 | 索引任务 | 转录任务
```

“转录任务”页面结构调整为：

```text
页面标题与说明
统计卡片
视频资源
视频资源列表
```

删除页面正文中的共享资料源面板和重复的“资料管理 / 转录任务”面包屑。列表标题使用“视频资源”，避免把媒体资源和转录任务记录混为一谈；列表内继续展示转录、审核、发布和索引状态，并显示来源标签（如“本地上传”“共享目录：培训视频”）。

转录配置不再作为转录任务页正文内容。它移动到管理员设置区域的独立入口。

## 共享资料源页面

共享资料源作为管理员设置中的独立页面，而不是普通弹窗。页面负责长期状态和操作：

- 已配置源列表；
- 启用/停用状态；
- 根别名和相对目录的产品化展示；
- 文件数量、缺失数量和最近扫描时间；
- 立即扫描；
- 扫描失败和不可用状态；
- 进入详情查看扫描摘要与最近记录。

新增和编辑共享源使用弹窗或抽屉，仅承载表单。文件浏览、扫描状态和错误信息留在独立页面，避免把长期管理工作塞进一次性浮层。

当服务端没有配置根别名时，独立页面显示明确的关闭状态和管理员配置提示；不向浏览器暴露宿主机绝对路径，也不弱化后端权限校验。

## 视频范围与未来文档范围

第一阶段维持视频专用能力：共享目录扫描 MP4，进入现有音频准备、ASR、审核、发布和索引链路。页面和文案明确使用“视频”或“视频资源”，不暗示已支持通用文件。

未来扩展普通文档时，产品名称可升级为“外部资料源”，但视频与文档必须进入不同处理队列：

```text
视频 -> 音频准备 -> ASR -> 转录稿 -> 审核/发布/索引
文档 -> 解析/OCR -> 文档版本 -> 审核/发布/索引
```

首批文档类型建议为 PDF、DOCX、PPTX、XLSX、Markdown 和 TXT；压缩包、可执行文件、宏文件和复杂图片 OCR 不纳入首批范围。文档扩展应另立 R2 设计，不能通过给视频表或“加入转录”按钮增加分支来实现。

## 组件与调用边界

- 继续复用现有资料管理子页面导航和统计卡片组件。
- 将 `ExternalMediaSourcesPanel` 从转录任务页移至新的管理员共享资料源页面容器。
- 复用现有 `adminMediaApi.externalRoots`、`externalSources`、扫描和更新接口；本阶段不变更接口契约。
- 视频资源列表只消费已有媒体/转录状态，新增来源展示应使用业务标签，不显示 UUID、请求 ID 或服务器路径。
- 新页面继续遵守管理员权限、CSRF、loading/empty/error/busy/disabled/success 状态要求。

## 验证方案

### 页面结构

- 桌面端 `1280x720`：子页面导航、统计卡片、列表标题和首屏操作可见。
- 移动端 `390x844`：无横向溢出，统计卡片和列表身份不被遮挡。
- 切换资料列表、索引任务和转录任务后，标题、统计和列表内容不串页。

### 状态与权限

- 转录任务页覆盖 loading、empty、error、busy 和 disabled 状态。
- 共享资料源页覆盖未配置根别名、无源、扫描中、扫描失败、源不可用和成功扫描。
- 管理员可访问和修改；普通用户无法访问设置页，也不能通过隐藏按钮绕过后端权限。

### 回归

- 运行前端构建和相关管理员页面单元测试。
- 运行现有外部媒体源 API 测试，确认接口和数据契约未改变。
- 使用脱敏 fixture 做真实浏览器验收，不使用真实共享目录或业务文件。

## 风险与回滚

主要风险是路由入口变化导致管理员找不到原配置入口，以及旧测试依赖共享资料源仍挂在转录任务页。通过保留明确的设置导航、更新页面测试和提供旧入口短期跳转可降低风险。

本阶段回滚只需恢复前端路由、页面组合和导航文案；不涉及数据库、索引、外部目录或生产数据，因此可由单个前端提交回滚。

## 实施顺序

1. 调整资料管理页面的标题层级、统计卡片和视频资源列表标题。
2. 新增管理员共享资料源路由和页面容器，迁移现有面板。
3. 将转录配置移动到管理员设置区域，并更新导航和权限状态。
4. 更新单元测试、浏览器验收 fixture 和相关功能文档。
5. 运行构建、相关测试和桌面/移动端视觉验收。
