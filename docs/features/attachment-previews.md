# 多格式附件、文件信息与轻量预览

## 状态与边界

已实现，已完成本地合成数据技术验证及远端 Linux CI 验证。生产部署与用户验收尚未完成；源码能力不表示已经上线。

本功能将资料管理和问答索引分离：附件可登记、发布、查看信息、预览和受控下载，但不进入 MinerU、Office 转换、模型解析服务、Embedding 或 Qdrant。既有 PDF、Markdown、Office、XMind 和视频流程保持各自契约。

新增的[附件检索与图片 OCR](<attachment-search.md>)提供独立文件卡、版本元数据和可选 OCR 文字检索，不改变上述 RAG 边界；其本地验证状态与远端 CI/用户验收独立记录。聊天窄接口允许登录用户发现/预览当前已发布且分类祖先允许聊天检索的附件，不授予全局 `item.view`；原管理端 `item.view` 与显式下载 `item.download` 边界保持。原生预览会发送必要源字节，不是 DRM；DWG/RVT 等不透明原文件不会借预览接口绕过下载权限。

| 格式 | 原文件信息与下载 | 首期预览 |
| --- | --- | --- |
| JPG/JPEG/PNG | 支持 | 浏览器图片预览 |
| DXF | 支持 | 本地轻量二维预览，非工程测量或打印保证 |
| IFC | 支持 | 本地轻量三维预览，失败可降级下载 |
| DWG/RVT/CHE/NWD/NWC/SKP/MAX | 支持 | 不承诺原生预览，可人工关联同版本 JPG/PNG/PDF |

`CAD` 按 DWG/DXF、`SU` 按 SKP 处理；不把软件简称当作任意文件后缀。CHE 仅作为不透明附件保存，不解析其内部格式。SKP 的独立原生查看器不属于首期保证能力。

本期不包含共享目录夜间自动同步、源目录写入、云转换、Revit/AutoCAD 运行节点、DWG GPL 转换器、模型属性问答、精确工程计算或全格式无损兼容。

## 调用链与契约

```text
上传或受控服务器导入
 -> content_objects / content_items / content_versions
 -> 待发布附件 -> 发布 head（跳过文档解析与向量索引）
 -> 版本信息 / 受控预览 / 受控原文件下载
```

- 预览以 `version_id` 定位，不要求存在 RAG Parent，不构造虚假引用或索引对象。
- 原文件、文件信息、关联预览和下载始终属于同一版本；更新原文件不会沿用旧版本的关联预览。
- 元数据中的 `rag_enabled=false` 表示该格式仅作附件；发布成功不代表可以进行内容问答。
- 文件信息和预览由后端执行 `item.view` 校验；显式下载执行 `item.download` 校验；关联预览上传需要 `item.publish` 和 CSRF。
- 匿名、未授权和已归档对象不得通过直接 URL 绕过限制；草稿与历史版本遵循后端的版本可见性规则，不能仅依赖前端隐藏按钮。
- 预览资源与依赖自托管，不向第三方查看网站上传资料，不加载模型中任意外部路径。浏览器获得预览字节不等于技术上禁止保存这些字节。
- 关联预览是人工提供的 JPG/PNG/PDF，不声称自动转换或与原生模型视觉完全一致；页面应明确标识。
- 文件操作写结构化审计；审计保留与源文件、版本及索引保留分别管理，至少保留 30 天。

## 实现入口与资源限制

- 类型白名单：[附件类型](<../../api/content_attachment_types.py>)；版本信息、预览与关联预览：[附件 API](<../../api/content_attachments.py>)；原文件下载沿用[受管资料 API](<../../api/routes_content.py>)。
- `GET /api/admin/content/versions/{version_id}/info` 返回所选版本信息；`GET /preview` 返回受保护的原生或关联预览。`POST /associated-preview` 接收人工预览附件，避免与既有 Office `POST /preview` 重新生成接口冲突。
- Schema 45 增量扩展附件类型、当前预览和历史对象引用；更换关联预览不丢失旧对象引用，永久清理时按跨版本引用检查回收，不触碰共享源。
- 前端使用[版本预览外壳](<../../frontend/src/components/AttachmentPreview.tsx>)；DXF 和 IFC 通过可终止的本地 Worker 运行；依赖及许可说明见[第三方查看器](<../../frontend/THIRD_PARTY_VIEWERS.md>)。
- 轻量预览读取最多 32 MiB、请求及解析分别设置 30 秒边界；图片在解码前检查头部，限制 8000 万像素与单边 32768；IFC 限制 50 万三角面和 5000 个几何片段。超限、损坏或加载失败仅降级，不表示原文件上传失败。原文件上传与授权下载仍遵守既有后端限额。
- 人工关联 JPG/JPEG/PNG/PDF 最大 32 MiB；新版本不继承旧版本的关联预览。查看权限允许读取必要的原生预览字节，不代表可以用 `download=false` 绕过 RVT/DWG/CHE 等不透明原文件的下载权限。
- `VITE_ATTACHMENT_MODEL_PREVIEW=false` 在重新构建后关闭 DXF/IFC 查看器，保留文件信息、授权下载及关联图片/PDF；不涉及索引 Reset 或删除原文件。

## 验证入口

新增后端测试：[附件生命周期与权限测试](<../../tests/test_content_attachments.py>)；前端单元测试：[格式识别测试](<../../frontend/src/lib/attachment-formats.test.ts>)；浏览器夹具：[附件预览视觉测试](<../../frontend/tests/visual/attachment-preview.spec.ts>)。现有资料库、下载、回收站、Schema 迁移、Office 发布与重新分类回归继续执行；新增附件测试已接入 required CI 的 `validate` 作业。

至少验证：

1. 每种附件的登记、文件信息和正确版本下载，下载哈希与上传一致。
2. 图片、DXF、IFC 的合成成功样例以及损坏、超限、取消和预览失败降级。
3. 草稿、已发布、更新版本、归档、匿名与普通权限账号，以及关联预览 CSRF。
4. 原有 PDF/Office/XMind/视频流程回归，不增加附件的解析或向量索引任务。
5. 前端构建、相关单元测试、视觉检查和真实浏览器桌面/移动端验收。

## 用户验收交接

技术验证完成后状态为“待用户验收”，不得自行宣称用户验收通过。

前置条件：已部署对应版本；准备有资料查看/下载权限的账号以及有上传/发布权限的账号。仅使用合成、无敏感信息的小文件，不使用客户模型或生产资料作普通测试。

1. 上传一张图片和一个非原生预览格式附件，查看信息中的文件名、类型、大小、版本与来源。
   - 预期：信息正确；附件明确不用于内容问答；原生不可预览格式不出现空白 PDF 页。
2. 打开图片、DXF、IFC 合成样例；缩放/平移或旋转，关闭后重新打开。
   - 预期：支持的格式显示内容；取消、失败和不支持时有解释及有权限时的下载入口。
3. 为一个 RVT/DWG/CHE 测试附件关联合成 JPG/PNG/PDF，然后打开该版本。
   - 预期：显示“关联预览”，不会把它误称为原生模型预览。
4. 上传同名新版本并查看两个版本。
   - 预期：明确区分版本；新版本不会继承旧版本的预览附件；原文件下载与选定版本一致。
5. 分别检查无下载权限账号、未登录浏览器，以及损坏的预览样例。
   - 预期：下载或直接受保护 URL 被后端拒绝；预览失败不影响其他资料和页面。
6. 在桌面和手机宽度检查核心操作、长文件名、加载/失败状态与关闭操作。
   - 预期：页面无横向溢出和遮挡，核心操作可发现并可使用键盘聚焦。

清理：本地合成测试环境按测试夹具销毁；线上验收产生的测试资料先记录名称并由管理员按既有回收站流程处理，不将物理删除、Reset 或生产恢复当作普通验收步骤。失败反馈应包含步骤、浏览器、角色、时间和错误文字，不提供密钥或真实资料。完成后请明确回复“验收通过”或失败步骤。
